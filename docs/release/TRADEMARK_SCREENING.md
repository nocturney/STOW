# STOW preliminary trademark/name screening

This is an engineering release note, not a legal clearance opinion.

## Status

**Manual clearance required before broadly marketed Stable/commercial release.**

A preliminary public-record/web screen found existing marks that use or contain **STOW**, including marks associated with warehousing/storage and software-related services in some jurisdictions. That does not by itself establish conflict, likelihood of confusion, territorial rights, class overlap, priority, or infringement.

The purpose of this document is to prevent the project from accidentally treating the product name as legally cleared merely because the GitHub repository and binaries can use it.

## Preliminary observations

- Public U.S. trademark aggregators show a live registered **STOW** mark associated with warehousing/storage systems and certain warehousing-related computer software/services.
- A separate live U.S. **STOW IT** registration covers software for locating/managing/leasing physical storage space.
- Canadian public trademark records contain historic and current marks/index headings using STOW or STOW-formative wording, across several unrelated goods/services.
- A preliminary public Israeli search did not surface an obvious exact STOW software registration in the web-indexed results reviewed, but that is not a complete registry clearance search.

## Required before Stable/commercial launch

Have qualified trademark counsel or a professional clearance provider search the relevant jurisdictions and classes for:
- exact STOW;
- phonetic/visual variants;
- STOW-formative software marks;
- relevant Nice classes, especially downloadable software and software services;
- unregistered/common-law use where relevant.

Record the resulting decision and any geographic/product limitations before treating the name as cleared.

## Re-screen triggers

Repeat the screening if:
- STOW becomes paid/commercial;
- distribution expands materially to new jurisdictions;
- the product category or marketing description changes;
- the logo/wordmark changes materially;
- a cease-and-desist, platform complaint, registry objection, or confusingly similar product is discovered.
