A calmer desktop starts here.

## Highlights

- Release Notes now open inside STOW instead of sending you to a browser. The window fetches the official GitHub Release body and renders it in-app, with a graceful offline/error fallback.
- Privacy, License, Open-source notices and credits are available offline from inside STOW and from the installed legal bundle.
- The release pipeline now produces a legal manifest, SPDX SBOM and a dedicated STOW-Legal.zip alongside the normal binaries.
- The legal manifest records the exact .NET and Windows Desktop runtime-pack versions used by the build and the SHA-256 of the Windows SDK-licensed D3DCompiler_47_cor3.dll component.

- First-time interactive installs now require explicit acknowledgment of STOW's MIT License and the applicable bundled third-party terms.
- First-time silent installs require /ACCEPTLICENSES=1. Existing installed copies can still upgrade silently without repeating the flag.
- Installer regression now verifies that a first-time silent install without acceptance is rejected, and that the installed legal bundle and acceptance record are present.
- Package-manager Stable publication remains intentionally blocked until the first-run license/third-party-term acknowledgment path for portable installs is resolved.

## Validation

This preview was built from the exact resolved .NET 10.0.12 / Windows Desktop 10.0.12 runtime packs, passed the full build/test suite, release/legal verification, installer legal regression, and in-app Release Notes/offline legal UI smoke.
