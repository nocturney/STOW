A calmer desktop starts here.

## Highlights

- Release packaging now includes the SHA-256 of the main `STOW-<version>-win-x64.zip` in the external `SHA256SUMS.txt`, in addition to STOW.exe, STOWSetup.exe, STOW-Legal.zip and the SPDX SBOM.
- The release/legal verifier now fails if the published ZIP is missing from `SHA256SUMS.txt` or its hash does not match.
- In-app Release Notes were live-validated against the published GitHub Release body.
- Privacy, License and Open-source notices were live-validated as offline in-app documents.
- Portable/package-manager first-run legal acknowledgment was live-validated end to end and no longer blocks the distribution design on legal-flow grounds.

## Validation

This preview is a packaging/integrity hardening release. It preserves the same runtime behavior as preview.4 while strengthening release verification and documenting the completed legal/UI acceptance tests.
