A calmer desktop starts here.

## Highlights

- Accessibility is now a first-class STOW product layer rather than an optional visual mode.
- Settings > Accessibility adds persistent 100%, 125%, 150% and 200% in-app text scaling, increased contrast and an optional Windows UI font.
- STOW now follows Windows Contrast Themes automatically and exposes clearer keyboard focus throughout the app.
- Main navigation supports Alt access keys, while forms, lists, sliders, dialogs and dynamic status messages expose improved UI Automation semantics for screen readers.
- Light and Dark palettes were corrected for small-text and interactive-control contrast, and layouts were hardened against clipping at large text sizes.
- Rules, Apps and About received additional wrapping/scrolling behavior so critical actions remain reachable at 200% text.

## Validation

- Live Session 1 accessibility smoke passed at 200% text across Apps, Rules, Focus, Insights, Settings and About, including access keys, Tab focus and named UI Automation controls.
- Contrast checks verified at least 4.5:1 for the corrected small muted/status text colors and at least 3:1 for interactive control borders.
- Trayify v0.3.3 live restore parity passed after the accessibility changes, including minimize/hide/restore, Electron HWND recreation, rules and Focus restoration.
- Automated Engine and Integration suites, release/legal verification, installer regression, package metadata validation, CI and CodeQL remain required release gates.
- This Preview is intentionally unsigned and does not claim formal accessibility certification or trademark clearance.
