A calmer desktop starts here.

## Highlights

- Focus presets are now persistent: save, reuse and delete named Keep visible setups, with unavailable managed apps handled safely instead of breaking the preset.
- Recurring Focus scheduling is operational with local weekday/time/duration controls, at-most-once occurrence tracking, overlap handling and the configured safe Focus-end behavior.
- Rules now support Minimize, Focus and Startup triggers. Focus rules can keep selected managed apps visible, while Startup rules apply once per observed app process PID without trapping manually restored windows in a re-stow loop.
- Scheduled Focus notifications are now a real, opt-in local Windows tray feature. They are disabled by default and notify only when scheduled Focus sessions start or end.
- GitHub Actions were hardened with pinned action revisions and CodeQL analysis.
- Stable-release compliance now includes an explicit manual trademark/name-clearance gate; this Preview does not claim trademark clearance.

## Validation

- Release builds preserve the Trayify v0.3.3 restore-safety contract and do not add external runtime PackageReferences.
- Focus presets, Focus rules, Startup rules and the Notifications setting were exercised through live Session 1 UI smokes with user-state backup/restore.
- Automated Engine and Integration suites pass; the two hardware/session-dependent Win32 parity cases remain intentionally live-only.
- Preview remains intentionally unsigned. Stable publication remains separately gated by signing, legal/release verification and manual trademark clearance.
