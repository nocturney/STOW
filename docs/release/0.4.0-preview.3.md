A calmer desktop starts here.

## Highlights

- Apps, Rules, Focus, Insights, Settings and About are now operational product surfaces rather than static scaffolds.
- App minimize rules can override the default stow behavior with priority-aware Keep visible rules.
- Focus sessions can temporarily stow distractions, preserve pre-existing stowed state and restore safely at session end.
- Insights now uses bounded local-only history with no telemetry or cloud account.
- Settings now persist theme, Windows startup, tray-close behavior and Focus-end behavior in a local settings file.
- About now exposes live version/build/channel data, the verified updater, local diagnostics, and current project/privacy/support links.
- The installer, migration path, updater and unsigned Preview release flow remain regression-gated.

## Validation

This preview passed the full local product smoke before publication: build/tests, live Win32 parity, installed UI navigation, and installer uninstall/reinstall retention checks.

Preview releases are intentionally unsigned. Windows SmartScreen may warn. Verify the published SHA-256 checksums before installation.
