# Support

For ordinary bugs and feature requests, use the STOW repository's GitHub Issues page and select the appropriate template.

When reporting a bug, include the STOW version, Windows version, affected application, and exact reproduction steps. The About > Diagnostics action provides a local diagnostic summary suitable for attaching to a report.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and use private vulnerability reporting rather than a public issue.
